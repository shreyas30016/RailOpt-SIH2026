# Environment Variables Specification

This document details every environment variable used across the RailOpt system.

---

## Core Server & Network Configuration

### `PORT`
- **Description**: Port number on which the FastAPI application listens.
- **Default**: `8000` (Locally), or dynamically injected by hosting platforms (e.g. Render, Railway, Heroku).
- **Example**: `8000`

### `CORS_ORIGINS`
- **Description**: Comma-separated list of allowed origins permitted to communicate with the FastAPI backend over CORS. Wildcard origins (`*`) disable credentials to comply with browser safety specifications.
- **Default**: `http://localhost:8000,http://127.0.0.1:8000,http://localhost:5500,http://127.0.0.1:5500`
- **Production Example**: `https://railopt-sih2026.vercel.app,http://localhost:8000`

---

## Database Configuration

### `DATABASE_URL`
- **Description**: Database connection string consumed by SQLAlchemy.
- **Default (Local)**: `sqlite:///<project_root>/railopt.db`
- **Production Example**: `postgresql://postgres:secretpassword@db.supabase.co:5432/railopt`
- **Note**: Supports any SQLAlchemy-compatible dialect (`postgresql://`, `mysql://`, `sqlite://`).

---

## AI Copilot Configuration

### `AI_PROVIDER`
- **Description**: Selects the active conversational model backend.
- **Options**: `nvidia` | `mock`
- **Default**: `mock` (If no API key is provided, falls back to deterministic rule-based grounding)

### `AI_API_KEY`
- **Description**: API authentication key for the chosen AI model endpoint.
- **Example**: `nvapi-xxxxxxxxxxxxxxxxxxxxxxxx`

### `AI_MODEL`
- **Description**: Specific model identifier to request from the provider.
- **Default**: `deepseek-ai/deepseek-v4-flash-0731`

### `AI_ENDPOINT`
- **Description**: Base URL for OpenAI-compatible completions API.
- **Default**: `https://integrate.api.nvidia.com/v1`

### `AI_MAX_TOKENS`
- **Description**: Maximum generation length for copilot responses.
- **Default**: `1024`

### `AI_TEMPERATURE`
- **Description**: Sampling temperature for creative vs deterministic responses.
- **Default**: `0.2`

---

## Train Tracking & Feeds

### `TRAIN_DATA_PROVIDER`
- **Description**: Determines whether train movement feeds are generated by timetable replay simulation or queried from an external live API.
- **Options**: `simulated` | `live`
- **Default**: `simulated`

### `LIVE_TRAIN_API_URL`
- **Description**: External endpoint URL when `TRAIN_DATA_PROVIDER=live`.
- **Default**: *None*

### `LIVE_TRAIN_API_KEY`
- **Description**: Authentication key for external live feed when configured.
- **Default**: *None*
